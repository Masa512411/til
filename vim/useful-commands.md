# Vim 有用コマンド一覧

## 1. 移動
| 操作 | 内容 |
| --- | --- |
| `h j k l` | 左 下 上 右 |
| `w` / `b` / `e` | 次の単語頭 / 前の単語頭 / 単語末 |
| `0` / `^` / `$` | 行頭 / 最初の非空白 / 行末 |
| `gg` / `G` | ファイル先頭 / 末尾 |
| `{n}G` or `:{n}` | n行目へ |
| `{` / `}` | 前 / 次の段落 |
| `%` | 対応する括弧へ |
| `f{c}` / `t{c}` | 行内で文字 c まで移動 / 手前まで |
| `;` / `,` | f・t を同方向 / 逆方向に繰り返す |
| `Ctrl-d` / `Ctrl-u` | 半画面スクロール |
| `Ctrl-o` / `Ctrl-i` | ジャンプ履歴を戻る / 進む |
| `*` / `#` | カーソル下の単語を前方 / 後方検索 |
| `H` `M` `L` | 画面の上 / 中 / 下 |

## 2. 編集
| 操作 | 内容 |
| --- | --- |
| `i` `a` | カーソル前 / 後に挿入 |
| `I` `A` | 行頭 / 行末に挿入 |
| `o` `O` | 下 / 上に新規行 |
| `x` | 1文字削除 |
| `dd` / `yy` / `p` / `P` | 行削除 / 行コピー / 後ろに貼付 / 前に貼付 |
| `D` / `C` | カーソルから行末まで削除 / 削除して挿入 |
| `cc` | 行を置換して挿入 |
| `r{c}` | 1文字置換 |
| `J` | 次の行を連結 |
| `u` / `Ctrl-r` | undo / redo |
| `.` | 直前の変更を繰り返す(最重要) |
| `~` | 大文字小文字を反転 |
| `>>` / `<<` | インデント増 / 減 |

## 3. オペレータ + テキストオブジェクト
形式は `{操作}{範囲}` です。これが vim の核心です。

| 操作 | 内容 |
| --- | --- |
| `d` `c` `y` `v` | 削除 / 変更 / コピー / 選択 |
| `iw` / `aw` | 単語 / 単語+空白 |
| `i"` / `a"` | 引用符の内側 / 引用符含む |
| `i(` `i{` `i[` | 括弧の内側(`ib` `iB` も同じ) |
| `it` / `at` | HTMLタグの内側 / タグ含む |
| `ip` / `ap` | 段落 |

例:
- `ciw`: 単語を変更
- `di"`: 引用符内を削除
- `ya{`: `{}` ごとコピー
- `dt,`: `,` の手前まで削除
- `d2w`: 2単語削除
- `3dd`: 3行削除

## 4. ビジュアルモード
| 操作 | 内容 |
| --- | --- |
| `v` / `V` / `Ctrl-v` | 文字 / 行 / 矩形選択 |
| `gv` | 直前の選択を再選択 |
| 矩形で `I` → 入力 → `Esc` | 複数行の行頭に一括挿入 |
| 矩形で `$A` | 複数行の行末に一括追記 |

## 5. 検索と置換
| 操作 | 内容 |
| --- | --- |
| `/word` `?word` | 前方 / 後方検索 |
| `n` / `N` | 次 / 前の検索結果 |
| `:noh` | 検索ハイライトを消す |
| `:%s/old/new/g` | 全体を置換 |
| `:%s/old/new/gc` | 1件ずつ確認して置換 |
| `:s/old/new/g` | 現在行のみ置換 |
| `:'<,'>s/a/b/g` | 選択範囲のみ置換 |
| `:g/pat/d` | パターンに合う行を削除 |
| `:g/pat/normal @q` | 合致行でマクロ実行 |

## 6. マクロ・レジスタ
| 操作 | 内容 |
| --- | --- |
| `qa` ... `q` | レジスタ a に記録開始 / 終了 |
| `@a` / `@@` | 実行 / 直前のマクロを再実行 |
| `10@a` | 10回実行 |
| `"ayy` / `"ap` | レジスタ a にコピー / 貼付 |
| `"+y` / `"+p` | システムクリップボードへコピー / から貼付 |
| `:reg` | レジスタ一覧 |

## 7. ファイル・バッファ・ウィンドウ
| 操作 | 内容 |
| --- | --- |
| `:w` / `:q` / `:wq` / `:q!` | 保存 / 終了 / 保存して終了 / 破棄して終了 |
| `ZZ` | 保存して終了 |
| `:e file` | ファイルを開く |
| `:ls` / `:b{n}` | バッファ一覧 / 切替 |
| `:bn` / `:bp` | 次 / 前のバッファ |
| `:sp` / `:vsp` | 水平 / 垂直分割 |
| `Ctrl-w h/j/k/l` | ウィンドウ間移動 |
| `Ctrl-w =` | ウィンドウ幅を均等化 |
| `:tabnew` / `gt` / `gT` | 新規タブ / 次 / 前のタブ |

## 8. マーク・ジャンプ
| 操作 | 内容 |
| --- | --- |
| `ma` / `'a` / `` `a `` | マーク設定 / 行へ / 位置へ |
| ``` `` ``` | 直前の位置に戻る |
| `gd` | 定義へジャンプ(ローカル) |
| `gf` | カーソル下のファイルを開く |
| `Ctrl-]` / `Ctrl-t` | タグジャンプ / 戻る |

## 9. 挿入モード中の便利キー
| 操作 | 内容 |
| --- | --- |
| `Ctrl-w` | 直前の単語を削除 |
| `Ctrl-u` | 行頭まで削除 |
| `Ctrl-o` | 1コマンドだけノーマルモード |
| `Ctrl-n` / `Ctrl-p` | 補完 |
| `Ctrl-r {reg}` | レジスタを貼付 |
| `Ctrl-[` | Esc の代わり |

## 習得の順序(おすすめ)
1. **まず**: `hjkl` `w b e` `0 $` `gg G` `i a o` `dd yy p` `u` `.`
2. **次に**: `ciw` `di"` `f` `t` `%` `*` `/` `:%s`
3. **その後**: ビジュアルブロック `Ctrl-v`、マクロ `q`、`:g`、分割ウィンドウ
4. **意識すること**: マウスや矢印キーを避け、`.` で繰り返せる形で編集します。

練習には `vimtutor`(ターミナルで実行)が便利です。
